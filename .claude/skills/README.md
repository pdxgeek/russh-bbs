| `rust-coding` | All Rust in this repo | Written here for russh-bbs, following the same structure and principles as the two below |

## Keeping them in sync

`pdxgeek/ai-skills` is the source of truth for `typescript-coding` and `java-coding`. Do not edit the copies here; change them upstream and re-copy, and update the commit above. `rust-coding` currently lives only here; it is intended to be added upstream once the owner is happy with it.
