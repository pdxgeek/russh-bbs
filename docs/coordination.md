The source of truth for who is doing what. Read it before starting. Claim a slice by changing its **Status** to `Claimed` with your branch name, in the first commit of your branch. Mark it `In review` when the PR opens and `Done` when it merges.

A slice with an unmet dependency is not claimable.

**Parallelism.** Slices run in parallel only when their Owns paths do not overlap and their dependencies are merged. Slices that add migrations to the same backend are serialized (B → C → D → E/F/H). Migration numbers are taken at merge time: merge `main` first, then number the migration.

M3 and later milestones are not claimable until the owner adds their slices here.
